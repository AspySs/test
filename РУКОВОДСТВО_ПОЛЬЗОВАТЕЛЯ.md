## 1. Вход в систему

Для работы в системе необходимо авторизоваться. Введите логин и пароль, выданные администратором.

**Уровни доступа:**
- **Пользователь (USER)** — доступ ко всем основным разделам
- **Администратор (ADMIN)** — дополнительный доступ к разделам «Сотрудники» и «Резервное копирование»

Для выхода из системы нажмите кнопку **«Выйти»** в нижней части бокового меню.

## 2. Расписание

Раздел отображает все активные бронирования в виде наглядной календарной диаграммы (Gantt).

### Что видно на экране
- **По вертикали** — список всех номеров (номер, название, этаж, вместимость)
- **По горизонтали** — дни текущего месяца
- **Цветные полосы** — бронирования: каждый номер имеет свой цвет

### Навигация
- Кнопки **«‹»** и **«›»** — переключение между месяцами
- На мобильных устройствах таблица прокручивается горизонтально

### Просмотр деталей
Нажмите на цветную полосу бронирования — появится всплывающее окно с информацией:
- Имя и фамилия гостя
- Город гостя
- Ссылка на редактирование бронирования

> Отменённые бронирования на диаграмме не отображаются.

## 3. Бронирования

Основной раздел для управления заселением гостей.

### Просмотр списка

Таблица показывает все бронирования со следующими данными:
- Гость (имя + количество гостей, если больше одного)
- Номер комнаты
- Дата заезда и выезда (с количеством ночей)
- Финансы: итоговая сумма, стоимость за ночь, предоплата, остаток к оплате
- Статус: **Активно**, **Предстоящее**, **Завершено**, **Отменено**
- Статус оплаты: **Оплачено** / **Не оплачено**

### Фильтры и поиск

Доступны следующие фильтры (можно применять одновременно):
- **Поиск по гостю** — введите имя или фамилию
- **Номер** — выберите конкретный номер из списка
- **Статус** — все, активные, предстоящие, завершённые, отменённые
- **Оплата** — все, оплаченные, неоплаченные
- **Период** — укажите диапазон дат (отображаются бронирования, пересекающиеся с периодом)

Под фильтрами отображается счётчик найденных записей.

### Сортировка

Щёлкните по заголовку столбца для сортировки. Повторный щелчок меняет направление (↑/↓). Доступна сортировка по:
- Номеру бронирования, имени гостя, номеру комнаты, дате заезда, дате выезда, сумме, количеству ночей

### Создание бронирования

Нажмите кнопку **«+ Новое бронирование»**. Заполните форму:

| Поле | Описание |
|------|----------|
| Гость | Выберите из списка гостей |
| Комната | Выберите из списка номеров |
| Дата заезда | Дата и время заселения |
| Дата выезда | Дата и время выселения |
| Итоговая сумма | Стоимость всего проживания (₽) |
| Стоимость за ночь | Цена одной ночи (₽) |
| Предоплата | Внесённая предоплата (₽) |
| Количество гостей | Число проживающих |

**Важно:**
- Дата выезда должна быть позже даты заезда
- Если номер уже занят в выбранный период, система не даст создать бронирование
- При создании бронирования автоматически создаётся задача «Уборка» на дату выезда
- Если предоплата равна или превышает итоговую сумму — бронирование автоматически помечается как оплаченное

### Редактирование бронирования

Нажмите кнопку **«Изменить»** (карандаш) в строке бронирования. Можно изменить любые данные, а также:
- Переключить статус (активно / отменено)
- Отметить бронирование как полностью оплаченное

### Оплата бронирования

В строке неоплаченного бронирования доступны два варианта:
- **«Оплатить»** — введите сумму частичного или полного платежа
- **«Отметить оплаченным»** — пометить как полностью оплаченное без ввода суммы

При накоплении достаточной суммы предоплаты бронирование автоматически помечается как оплаченное.

### Удаление бронирования

Нажмите кнопку **«Удалить»** (корзина) — появится запрос на подтверждение.

## 4. Номера

Управление номерным фондом отеля.

### Список номеров

| Столбец | Описание |
|---------|----------|
| Название | Имя номера (например, «Люкс», «Угловая») |
| Этаж | Расположение |
| Вместимость | Максимальное количество гостей |
| Статус | Текущее состояние номера |

**Статусы номеров:**
- **Свободен** (зелёный) — номер доступен для заселения
- **Занят** (красный) — есть активное бронирование на текущую дату
- **Обслуживание** (жёлтый) — номер временно недоступен (ремонт, уборка и т.д.)

### Создание номера

Нажмите **«+ Добавить номер»** и заполните:
- Название (необязательно)
- Цвет для отображения в расписании (выбор из палитры)
- Этаж
- Вместимость
- Начальный статус

### Редактирование и удаление

Используйте кнопки в строке номера. Статус можно изменить в любой момент.

## 5. Гости

Управление базой данных гостей.

### Список гостей

Отображаются: имя, фамилия, телефон, город, возраст, номер группы, паспорт, дата последнего заезда.

### Поиск и фильтры

- **Поиск** — по имени, фамилии или телефону
- **Город** — выберите из выпадающего списка
- **Возраст** — укажите диапазон (от / до)
- **Группа №** — фильтр по номеру групповой брони

Кнопка **«Сбросить»** очищает все фильтры.

### Создание гостя

Нажмите **«+ Добавить гостя»** и заполните данные:

| Поле | Обязательное |
|------|-------------|
| Имя | Да |
| Фамилия | Да |
| Телефон | Да |
| Город | Нет |
| Возраст | Нет |
| Паспорт | Нет |
| Группа № | Нет (для групповых бронирований) |

### Редактирование и удаление

Используйте кнопки в строке гостя. Удаление требует подтверждения.

## 6. Задачи

Управление служебными поручениями и задачами персонала.

### Список задач

Каждая задача содержит:
- Тип задачи (с цветной меткой)
- Номер комнаты
- Ответственный сотрудник
- Дата и время выполнения
- Статус: **В работе** / **Выполнена**
- Пометка **«авто»** — если задача создана автоматически при оформлении бронирования

### Фильтры

- **Статус** — все, в работе, выполненные
- **Тип** — фильтр по типу задачи
- **Сортировка** — по дате (возрастание / убывание)

### Создание задачи

Нажмите **«+ Добавить задачу»**:
- Комната (необязательно)
- Ответственный сотрудник (необязательно)
- Дата и время
- Тип задачи

### Редактирование задачи

Можно изменить любые поля и переключить статус (в работе ↔ выполнена).

### Управление типами задач

Нажмите кнопку **«Типы задач»** для управления справочником:
- Просмотр всех существующих типов (с цветом)
- Создание нового типа (название + цвет)
- Удаление типа

> Типы задач используются для категоризации: уборка, техническое обслуживание, доставка и т.д.

## 7. Сотрудники *(только для администратора)*

Управление учётными записями персонала.

### Список сотрудников

Отображаются: ФИО, должность, телефон, логин, статус (активен / неактивен).

### Создание сотрудника

Нажмите **«+ Добавить сотрудника»**:

| Поле | Описание |
|------|----------|
| Имя / Фамилия | ФИО сотрудника |
| Телефон | Контактный номер |
| Должность | Роль: Пользователь (USER) или Администратор (ADMIN) |
| Логин | Уникальный логин для входа в систему |
| Пароль | Пароль (хранится в зашифрованном виде) |
| Зарплата | Необязательно |

Логин должен быть уникальным — система предупредит, если такой уже существует.

### Редактирование сотрудника

Все поля редактируемы. Если оставить поле пароля пустым — пароль не изменится. Можно деактивировать учётную запись (статус «неактивен») без удаления.

### Удаление

Требует подтверждения.

## 8. Аналитика

Раздел для анализа показателей работы отеля за выбранный период.

### Выбор периода

- **Быстрые кнопки:** Этот месяц, Прошлый месяц, 30 дней, 7 дней
- **Произвольный период:** укажите даты вручную и нажмите «Применить»

По умолчанию показывается текущий месяц.

### Финансовые показатели

| Показатель | Описание |
|------------|----------|
| Выручка за период | Суммарный доход от бронирований (₽) |
| Средняя цена за ночь (ADR) | Средняя стоимость одной ночи (₽) |
| Средний чек бронирования | Средняя сумма одного бронирования (₽) |
| Доход на человека | Выручка в пересчёте на одного гостя (₽) |

### Показатели загрузки

| Показатель | Описание |
|------------|----------|
| Загрузка номеров | Процент занятости номерного фонда |
| Количество бронирований | Общее число бронирований за период |
| Количество ночей | Суммарное число ночей проживания |
| Среднее число ночей | Средняя длительность одного бронирования |

### Операционные показатели

| Показатель | Описание |
|------------|----------|
| Отмены бронирований | Процент отменённых бронирований |
| Средний размер группы | Среднее количество гостей на одно бронирование |

> Загрузка номеров выделяется цветом: зелёный ≥ 70%, синий ≥ 40%, жёлтый < 40%.

## 9. Резервное копирование *(только для администратора)*

Управление резервными копиями базы данных.

### Создание резервной копии вручную

Нажмите кнопку **«Создать бэкап сейчас»** — система немедленно создаст резервную копию базы данных.

### Автоматическое резервное копирование

Система автоматически создаёт резервные копии по расписанию (ежедневно в 3:00 по умолчанию).

### Отправка в Telegram

Резервные копии можно автоматически получать в Telegram-чат. Настройка производится администратором сервера. При наличии настройки — бэкап отправляется в Telegram автоматически.

### Просмотр и загрузка

В разделе отображается список созданных резервных копий. Каждую можно скачать на компьютер.

## Общие советы

- **Мобильный доступ:** система адаптирована для смартфонов и планшетов. Часть столбцов таблиц скрывается на маленьких экранах для удобства.
- **Подтверждение удаления:** при любом удалении данных система запрашивает подтверждение — случайно ничего не потеряется.
- **Автоматические действия:** при создании бронирования автоматически создаётся задача на уборку номера после выезда.
- **Фильтры работают вместе:** можно одновременно применить несколько фильтров для точного поиска нужных данных.
